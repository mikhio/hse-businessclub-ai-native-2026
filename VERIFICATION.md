## Воспроизведение

```bash
docker compose up --build -d --wait
docker compose --profile test run --rm tests
```

Каждый API-тест создаёт свою случайную PostgreSQL schema и удаляет только её после завершения. Таблицы и строки демонстрации не удаляются. Проверки конкуренции используют реальные параллельные соединения PostgreSQL.

Для проверки браузером:

```bash
npm install --no-save --package-lock=false playwright
npx playwright install chromium
node tests/browser.mjs
```

В машине исполнителя использовались Chromium 1234 из имеющегося кеша и отдельные контексты браузера. Основные API-проверки сделаны на Docker Compose project `hse_ai_native_20261024`. Чистый старт проверен отдельным project `hse_ai_native_clean_20261024` с портом 8174 и новым volume; после проверки именно этот временный project остановлен и его тестовый volume удалён. Основное демонстрационное приложение оставлено healthy на loopback-порту 8173.

Скриншоты браузерного сценария формируются в `artifacts/` и не коммитятся: `desktop-feed.png`, `desktop-incoming.png`, `mobile-result.png`, `mobile-feed.png`, `docs.png`. Данные на них вымышленные.

Независимое ревью исходной версии обнаружило блокировку Swagger глобальной CSP. Исправление ограничено маршрутом `/docs`: CDN-ресурсы Swagger разрешены только там, а инициализатор получает одноразовый nonce; основной интерфейс сохраняет прежнюю CSP. Финальный browser-run после исправления проверил и документацию, и пользовательский сценарий.
